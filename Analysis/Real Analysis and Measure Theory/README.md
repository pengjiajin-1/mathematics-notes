# Real Analysis and Measure Theory

Notes on Real Analysis and Measure Theory.

内容包括测度论基础、可测函数性质、收敛定理以及 $L^p$ 空间基本性质。

其中测度论内容主要参考: 
- Evans《Measure Theory and Fine Properties of Functions》
- Lieb and Loss《Analysis》
- Rudin《Real and Complex Analysis》
- 严加安《测度论讲义》
- Wheeden and Zygmund《Measure and integral: an introduction to real analysis》（勒贝格测度的直接构造）
